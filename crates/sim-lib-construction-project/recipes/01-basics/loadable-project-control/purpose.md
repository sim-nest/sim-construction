# Loadable construction project control

The standard SIM boot path loads the Lisp codec, binding organ, and the one
`sim/construction-project` library. The specimen then constructs durable
Citizen data, opens an in-memory project book, appends one accountable fact,
rebuilds the historical sequence-one snapshot, and asks for an actionable
explanation of its blocker.

The book is a live opaque handle. Facts, snapshots, and reports are semantic
read-construct Citizens and round-trip through installed general-purpose
expression codecs. No construction parser, matcher, storage backend, host
effect, vendor API, or alternate runtime is involved.
